# EDA в E-commerce: поиск признаков для прогноза покупки

Разведочный анализ датасета интернет-магазина. Цель — понять, какие признаки сильнее всего связаны с фактом покупки, и подготовить данные к построению модели бинарной классификации.

## Данные
Файл `ecommerce.csv` содержит 390 наблюдений и 6 признаков:
- `время_на_сайте_мин` — числовой
- `просмотрено_товаров` — числовой
- `источник` — категориальный (поиск, реклама, соцсети, прямой)
- `промокод` — категориальный (да/нет)
- `покупка` — целевая переменная (бинарная: да/нет)

## Что сделано
- Загрузка и проверка типов данных.
- Описательная статистика и частоты категорий.
- Анализ пропусков (обнаружено ~5% пропусков в двух столбцах).
- Визуализация: гистограмма, boxplot, столбчатые диаграммы, scatter, тепловая карта корреляций.
- Сравнение распределений признаков по классам.

## Ключевые выводы
1. **Время на сайте** — сильный признак: среднее у купивших 5.95 мин, у не купивших — 3.38 мин.
2. **Промокод** повышает конверсию: 60.9% покупок с промокодом против 44.0% без него.
3. **Источник трафика** влияет: прямой трафик даёт лучшую конверсию (55.9%), реклама — худшую (43.5%).
4. **Мультиколлинеарности нет**: корреляция между числовыми признаками ~0.003.
